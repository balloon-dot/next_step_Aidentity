# Профи — демонстрационный прототип
Статический HTML/CSS/JS. Открыть dist/index.html через HTTP-сервер.
Данные — localStorage; PDF — IndexedDB. Без серверной регистрации и межустройственного сбора оценок.
33 кластера, capacity-constrained power diagram, пропорциональное перераспределение долей. Перетаскивание выбранной области вверх/вниз меняет оценку.
Публикация Sites приватная. Для реальных приглашений нужны серверная база, авторизация и настройка доступа.

Обновление: шкала качеств 1–30. Сумма баллов кластеров постоянна (330); площади равны баллам / 330. При достижении границ 1 или 30 остаток распределяется между остальными кластерами. Вложенные качества имеют независимые оценки 1–30.
«Поделиться» формирует ссылку со снимком результатов в URL-фрагменте: баллы, признаки редактирования и вложенные качества. Снимок открывается на другом устройстве без доступа к локальному хранилищу владельца. Персональные поля и PDF не включены. Ссылка не обновляется автоматически.
